💻 使用

- 下载并解压。
- 主要文件：
- /static/root.css：主题样式文件。
- /static/style.css：样式文件，可修改字体。
- /static/img/favicon.ico：网页图标和头像。
- /static/script.js：JS 功能文件。

- HTML
- CSS
- JavaScript
